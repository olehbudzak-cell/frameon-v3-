# Frameon Drylining — сайт v2 (Next.js)

Новий преміальний 3D-сайт для frameondrylining.co.uk. 12 мов, як на старому сайті: English (головна, без префікса), Română, Español, Polski, বাংলা, Português, ગુજરાતી, Italiano, ਪੰਜਾਬੀ, العربية (справа наліво), Українська, Русский.

## Запуск на комп'ютері (Windows)

1. Встановіть Node.js 20 або новіший: https://nodejs.org
2. Розпакуйте архів, відкрийте папку в терміналі (PowerShell) і виконайте:
   ```
   npm install
   npm run dev
   ```
3. Відкрийте http://localhost:3000 — англійська версія; /ro, /es, /pl, /bn, /pt, /gu, /it, /pa, /ar, /uk, /ru — інші мови.

Production-збірка: `npm run build` і `npm start`.

## Що де лежить

- `src/content/en.ts`, `uk.ts`, `ru.ts`, `pl.ts`, `ro.ts` — усі тексти сайту. Щоб змінити текст, правте ці файли.
- `src/content/services.ts` — список послуг, ставки (£/м²), телефон, email, WhatsApp.
- `public/scene/` — кадри 3D-сцени (з відео Higgsfield), яку прокручує скрол.
- `public/images/` — рендери Higgsfield з англійськими назвами файлів для SEO.
- `src/components/` — компоненти: BuildScene (скрол-сцена), XRay, калькулятори, шапка, футер.

## Мови

- EN — без префікса (`/`), решта — з префіксом мови (`/ar`, `/uk`…), з hreflang. Арабська відображається справа наліво.
- Для бенгальської, гуджараті, пенджабі й арабської підключено шрифти Noto.
- Повні сторінки послуг і сторінка «Для підрядників» — англійською та українською.
  Для інших 10 мов посилання на послуги ведуть на англійські сторінки (щоб не було дублікатів для Google).

## Перед публікацією

- Додати реальні фото робіт (портфоліо) — секцію «Роботи» на головній ще не додано, бо там мають бути лише реальні фото. Facebook уже підключено.
- Форма «Отримати ціну» працює без сервера: відкриває WhatsApp або лист із заповненим текстом.
- Створити Google Business Profile — найважливіше для локального пошуку.
- Деплой: новий проєкт на Vercel або заміна поточного — лише коли скажете.
